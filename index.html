🎯 Escopo do Projeto

✓ MVP (Fase 1): Integração de plataforma com WMS local, criação de dashboard de estoque em tempo real para hub central.

✓ Fase 2: Expansão para 3 hubs regionais (SP, MG, RS) com sincronização automática.

✓ Fase 3 (Opcional): Abertura de API para vendedores terceirizados integrem seus estoques.

🚀 Oportunidades Identificadas

Conectar dashboard com pedidos de marketplaces para planejamento de estoque preditivo.

Sistema de estoque atual é de 2008 — migração deve ser em phases para não parar operações.

Gerentes de hub podem resistir a mudança de rotina — precisa de treinamento personalizado e early wins.
